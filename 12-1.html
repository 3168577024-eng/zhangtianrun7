CSS 变量演示

使用 CSS 自定义属性（Custom Properties）管理颜色、尺寸等主题值

1. 定义变量

在 :root 中声明全局变量，供整个页面引用

:root {
    --ztr_primary: #d9684e;
    --ztr_ink: #19302c;
    --ztr_radius: 12px;
}

2. 使用变量

通过 var() 函数引用变量值

.ztr_btn {
    color: var(--ztr_ink);
    border-radius: var(--ztr_radius);
}

3. 变量修改变更

局部作用域覆盖全局变量，实现主题切换

.ztr_interactive {
    --ztr_local: #4e8d7b;
}
body.ztr_dark {
    --ztr_paper: #1a2521;
    --ztr_ink: #e8f0ea;
}
