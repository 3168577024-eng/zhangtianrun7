CSS 变量演示

使用 CSS 自定义属性（Custom Properties）管理颜色、尺寸等主题值

1. 定义变量

在 :root 中声明全局变量，供整个页面引用

:root {
    --zhang_primary: #d9684e;
    --zhang_ink: #19302c;
    --zhang_radius: 12px;
}

2. 使用变量

通过 var() 函数引用变量值

.zhang_btn {
    color: var(--zhang_ink);
    border-radius: var(--zhang_radius);
}

3. 变量修改变更

局部作用域覆盖全局变量，实现主题切换

.zhang_interactive {
    --zhang_local: #4e8d7b;
}
body.zhang_dark {
    --zhang_paper: #1a2521;
    --zhang_ink: #e8f0ea;
}
